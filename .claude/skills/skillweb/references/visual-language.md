# 비주얼 언어 — 수집한 레퍼런스에서 실제로 관찰한 패턴

`visual-ref/`에 모아둔 24,000여 프레임 중 대표 프레임을 샘플링해서 직접 확인한 결과다. 여기 적힌 건 감상이 아니라 실제로 화면에 나온 것들이다. 이 문서는 §1(핵심 은유)과 §4.0(톤 리서치)에서 "뭘 참고할지" 막힐 때 근거로 쓴다. 실제 구현 코드는 여전히 `canvas-particles.md`/`slide-engine.md`/`threejs.md`/`manim-python-scenes.md`를 쓴다 — 이 문서는 그 코드에 넣을 파라미터(색·모티프·타이포)를 고르는 근거다.

샘플링 커버리지: `fourier`, `3blue1brown/*`, `matrixinvite`, `bestmotion2022`, `showreel2024`, `monochrome`, `motiongraphicsreel`, `virtualcity`, `typography/*`(별도 `typography.md`) + `playlist_01/03/04/06/07/08/09/10/11/12/13/14`(14개 재생목록 전부, 폴더당 3장씩) + `titlegraphics`/`short1`/`short2`(§3, 소재 아님으로 확인). `playlist_02`는 폴더 자체가 없음(미다운로드). `raw/`는 프레임이 아니라 원본 mp4라 스킵(같은 내용이 각 `-frames/` 폴더에 이미 추출돼 있음). 전수조사가 아니라 폴더당 소수 샘플링이라는 점은 감안할 것.

## 1. 압도적으로 반복되는 배경: 검은색/거의 검은색

`fourier-frames`, `3blue1brown/*`, `matrixinvite-frames`, `bestmotion2022-frames`, `playlist_13`, `showreel2024-frames` 전부 배경이 순검정 또는 거의 검정(`#0a0a0f` 급)이었다. 수학/테크/사이버 계열은 예외 없이 검정 배경 + 1~2개 포인트 컬러 조합이었다. `references/canvas-particles.md`의 배경색 기본값이 이미 이 관찰과 일치한다 — 프로젝트가 밝은 톤을 특별히 요구하지 않는 한 검정 배경을 기본으로 유지한다.

## 2. 도메인별 실제 관찰된 모티프

### 수학/알고리즘/설명 (Fourier, 3Blue1Brown 계열)
- 검정 배경 + 가는 원형 궤도선(옅은 회색, 겹겹이) + 흰색 벡터 화살표 체인 + 청록(cyan)/분홍 포인트 컬러의 궤적선. 원(epicycle)들이 중첩되며 하나의 곡선을 그려내는 구성 — "여러 개의 단순한 회전이 모여 복잡한 궤적을 만든다"는 걸 시각적으로 그대로 보여줌.
- `NumberPlane` 격자(청록색 얇은 그리드 라인)가 자주 등장 — 좌표/수식 맥락을 줄 때.
- 신경망 설명 영상은 원(노드) + 선(가중치 연결) 다이어그램, 값에 따라 노드 색이 흰색↔회색으로 채워짐. 우측 상단에 손글씨 숫자 썸네일이 흰 테두리 박스로 삽입됨.
- 텍스트는 거의 항상 흰색, 얇은 산세리프, 좌측 정렬 불릿.
- → `canvas-particles.md` 패턴 A(노드-연결 네트워크)가 정확히 이 스타일과 맞는다. 색은 `#ffffff` 선 + `#00e5c7`(청록) 또는 `#ff6b9d`(분홍) 포인트 하나만 쓴다. Manim 특유의 곡선 궤적이 꼭 필요하면 `manim-python-scenes.md` 사용.

### 프리미엄/미니멀 (monochrome, showreel2024)
- 완전 그레이스케일. 부드러운 3D 폼(듄/웨이브 형태)에 스튜디오 조명 하나만 — 그림자가 부드럽고 하이라이트가 넓게 퍼짐. 색이 아예 없는 게 오히려 고급스러워 보이는 케이스.
- 하단에 점(dot) 형태의 캐러셀 인디케이터 — 우리 `slide-engine.md`의 progress dot과 톤이 통일된다.
- → 헬스케어/핀테크처럼 "신뢰감·프리미엄"이 필요한 프로젝트는 컬러를 아예 빼고 흑백 그라디언트 3D로 가는 것도 강력한 선택지. `threejs.md`의 `MeshStandardMaterial` + 단일 라이트로 재현 가능(재질 색을 회색 계열로).

### 사이버/네온/테크 (matrixinvite, virtualcity)
- matrixinvite: 진한 빨강 단색 + 랜덤 숫자 매트릭스 레인 효과, 볼드 산세리프 타이틀이 그 위에 얹힘. 협박적/긴급한 느낌.
- virtualcity: 남색~네이비 배경에 시안/마젠타/퍼플 네온 글로우가 건물 윤곽을 따라 빛남, 등각(isometric) 느낌의 미래도시. 회로기판 패턴이 바닥에 깔림.
- → 보안/이상탐지/IoT 프로젝트에 적합. `canvas-particles.md` 패턴 B(데이터스트림)의 색을 네온 시안/마젠타로 바꾸고, 배경에 격자선을 살짝 깔면 이 느낌이 난다.

### 브랜드/타이틀 카드 (playlist_09의 "BREAKOUT" 카드)
- 굵은 산세리프 텍스트를 **면(solid) 버전 + 외곽선(outline) 버전을 겹쳐서** 배치 — 좌우로 살짝 어긋나게 겹치면 입체감/에너지가 생김. 배경은 어두운 네이비에 큰 원형 도형 실루엣.
- → Hero 슬라이드 타이틀에 바로 적용 가능한 값싼 트릭: 같은 텍스트를 두 번 그리되 하나는 `-webkit-text-stroke`만, 하나는 채우기만 쓰고 몇 px 오프셋.

### 캐릭터/스토리텔링 (motiongraphicsreel, playlist_05/13)
- 플랫 컬러 2D 캐릭터 일러스트, 파스텔~비비드 톤 자유. 화면 좌하단에 반투명 검정 바 + 흰 볼드 텍스트로 "제작자/타이틀" 크레딧 — 이 크레딧 바 컨벤션이 어워드 릴 전반에서 거의 고정 패턴이었다.
- → 우리 슬라이드의 팀명/Hero 캡션 배치에 이 "좌하단 크레딧 바" 컨벤션을 그대로 쓸 수 있다 (Impact/Closing 슬라이드의 팀원 크레딧에 적합).
- **(playlist_01/03/04/06/07/08/10/11/12/14 추가 샘플링으로 확인)** 이 좌하단 크레딧 바는 캐릭터/스토리텔링 장르 한정이 아니라 신스웨이브·3D클레이·로우폴리·다큐 타이틀카드 등 **장르 불문 거의 전 장르에서 나오는 범용 컨벤션**이었다. 팀명/제작 크레딧을 넣을 위치를 고민할 필요 없이 이 자리를 기본값으로 써도 된다.

### 레트로/신스웨이브 (playlist_03)
- 네온 퍼플→핑크→레드 수직 그라디언트 하늘, 실루엣 도시 스카이라인, 플랫 벡터 컨버터블 자동차, 야자수/식물 실루엣 전경. 채도 높은 단색 면 위주(그라디언트 메시 없이 색상 밴드로만 하늘을 표현).
- → 음악/엔터테인먼트/라이프스타일 프로젝트의 Hero 배경에 적합. `canvas-particles.md` 배경을 그라디언트 밴드(보라→핑크→주황)로 바꾸고 실루엣 도시 SVG를 하단에 깔면 재현된다.

### 다크 시네마틱 타이틀카드 (playlist_10, playlist_12 — Farcry 6 Title Sequence)
- 순검정~진한 레드/네이비 배경, 중앙에 원형 또는 단일 오브젝트(자동차 등)만 스포트라이트로 강조, 나머지는 어둠에 묻힘. 타이틀 텍스트는 얇고 절제된 세리프/산세리프, 화면 하단에만 작게 배치. 앞서 §2 "브랜드/타이틀 강조"(BREAKOUT, 면+외곽선 겹침)보다 훨씬 절제되고 무거운 톤 — 유머/에너지가 아니라 **진지함/서스펜스**를 낼 때 쓰는 변형.
- → 사회문제/헬스케어/보안처럼 무게감이 필요한 프로젝트의 Hero 타이틀에 적합. 큰 원형 vignette(중앙 밝고 가장자리 어두움) + 단일 포인트 오브젝트 실루엣 하나만 남기는 구성.

### 로우폴리/블록 3D 아이소메트릭 (playlist_12 — Armstrong, cubstudio)
- 진한 블루/네이비 단색 배경에 둥근 모서리 블록 형태의 로우폴리 3D 오브젝트(건물처럼 단순화된 캡슐형)가 아이소메트릭 각도로 배치, 작은 플랫 캐릭터가 그 사이를 지나감. `virtualcity`의 네온 사이버 아이소메트릭보다 훨씬 부드럽고 장난감 같은(파스텔에 가까운 단색) 톤.
- → 게임/시뮬레이션/도시 데이터 프로젝트에서 `virtualcity`보다 더 친근하고 부드러운 톤이 필요할 때의 대안. `threejs.md`의 낮은 폴리곤 지오메트리 + flat shading으로 재현.

### 필름 그레인/노이즈 오버레이 (playlist_01 — Nerdo)
- 세이지그린/크림 무채색 일러스트 위에 전체 화면에 걸쳐 미세한 입자 노이즈(필름 그레인)가 깔려 고급스러운 인쇄물/아날로그 질감을 냄. 색 자체보다 이 텍스처 하나로 "저예산 flat" 느낌을 벗어남.
- → 값싸게 고급감을 낼 수 있는 범용 트릭: CSS에서 SVG `feTurbulence`로 만든 노이즈 PNG/data-URI를 `mix-blend-mode: overlay`로 낮은 opacity(6~10%)로 전체 배경 위에 얹는다. 특정 장르 한정이 아니라 아무 팔레트에나 얹을 수 있는 마감 단계 트릭.

## 3. 참고용이었지만 코드 소재로 쓰지 않는 것

- `titlegraphics-frames`, `short1/2-frames`: 실제 화면은 튜토리얼/AI 툴 UI 스크린레코딩(애프터이펙트 타임라인, 챗 UI, 키보드 클로즈업)이라 비주얼 자체보다 "이런 AI 툴로 모션그래픽을 만드는 과정"을 보여주는 참고였다. 여기서 훔쳐올 그래픽 요소는 없음 — 다만 "말/텍스트 입력만으로 모션그래픽이 나온다"는 이 스킬의 지향점과 정확히 같은 컨셉이라 방향성 참고용으로 남겨둔다.
- `playlist_01/03/04/06/07/08/10/11/12/14` 공통 노이즈: 이 "Best Motion Design" 계열 재생목록들은 편집 중간에 **인스타그램 게시물 캡처나 Skillshare 강의 화면**을 그대로 잘라 넣은 컷이 다수 섞여 있다(작품 출처 표시용으로 추정). 이런 프레임은 실제 모션그래픽이 아니라 UI 스크린샷이므로 팔레트/모티프 소재로 쓰지 않는다 — 샘플링할 때 이런 프레임이 걸리면 건너뛰고 다음 프레임을 볼 것.

## 4. 요약 — 도메인 → 팔레트/모티프 매핑 (SKILL.md §1.3 보완)

| 신경망/AI 구조 | 검정 | 흰색(단색), 활성값만 포인트 컬러 | 노드-엣지 다이어그램 |
| 프리미엄/헬스케어/핀테크 | 흰색~회색 그라디언트 | 없음(무채색) | 부드러운 3D 폼, 단일 광원 |

| 브랜드/타이틀 강조(경쾌) | 다크 네이비 | 텍스트 자체 | 면+외곽선 겹친 타이포그래피 |
| 브랜드/타이틀 강조(진지) | 순검정/진한 레드 | 없음(모노) | 중앙 vignette + 단일 오브젝트 스포트라이트 |
